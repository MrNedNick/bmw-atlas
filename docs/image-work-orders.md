# Задания на изображения BMW X и Z

## Единый визуальный стандарт

Каждое изображение показывает точный кузов и точную фазу обновления. Автомобиль целиком находится в кадре, снят в ракурсе три четверти спереди, без обрезанных колёс, людей, текста, водяных знаков и чужих эмблем. Соотношение сторон — 16:10, минимальный размер — 1600×1000, итоговый формат — WebP.

Сцена продолжает текущий стиль BMW Atlas: спокойный тёмный студийный фон, мягкий направленный свет, естественные отражения, реалистичная оптика и нейтральный цвет кузова. Дизайн автомобиля сверяется с официальной фотографией из `sourceIds`; соседнее поколение или рестайлинг не используется как замена.

## Одна задача

1. Взять первую запись из `bmwXZImageTasks` в `src/data/packs/bmw-x-z/manifest.ts`.
2. Открыть все её `sourceIds` в `src/data/sources.ts` и проверить решётку, фары, бамперы, зеркала, колёсные арки, крышу и заднюю светотехнику.
3. Создать один исходный визуал по стандарту выше. Для фаз `lci-*` явно сопоставить отличия с дорестайлингом.
4. Сохранить файл строго в `outputFile` из задания. Не заменять изображения других фаз.
5. Добавить запись в `src/data/assets/index.ts`: локальный URL, точное название кузова и фазы, страница происхождения, правовой статус и alt.
6. Перевести только выполненную фазу из `needed` в `available`. Следующую запись не трогать.
7. Выполнить `npm run format`, `npm run check`, `npm test`, `npm run data:validate` и `npm run build:pages`.
8. Открыть прямую ссылку поколения на ширине 360 и 1440 px. Проверить полный автомобиль в кадре, подпись, светлую и тёмную темы, отсутствие 404 и горизонтальной прокрутки.

## Критерии готовности

- Файл соответствует точному поколению и визуальной фазе.
- Дорестайлинг и LCI имеют разные файлы и различимы по подтверждённым деталям.
- Полный автомобиль виден при `object-fit: contain`; важные части кузова не скрыты.
- Источник и правовой статус заполнены в реестре, даже если подпись источника свёрнута в интерфейсе.
- Валидатор больше не включает выполненную фазу в очередь.
- Все проверки проходят, а опубликованная прямая ссылка загружает изображение.

Машиночитаемая очередь формируется как `bmwXZImageTasks`. В текущем срезе она содержит отдельные задания для каждого отсутствующего дорестайлинга и каждого подтверждённого рестайлинга X1–X7 и Z.
